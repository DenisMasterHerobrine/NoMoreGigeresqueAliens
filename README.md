# NoMoreGigeresqueAliens

Server-side NeoForge addon for Gigeresque that gives pack/server owners stricter control over alien spread.

By default it disables Gigeresque alien egg biome spawns, Pandora egg spawning, eggmorphing, spore infection, and Gigeresque dungeon biome tags. Direct entity blocking is opt-in through the server config.

Requires Minecraft 1.21.1, NeoForge, and Gigeresque.

Configuration is generated at `config/nomoregigeresquealiens-server.toml`.
